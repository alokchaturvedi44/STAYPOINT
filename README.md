# STAYPOINT

STAYPOINT is a full-stack MERN application focused on building a scalable and user-friendly platform with clean backend architecture and real-world development practices.

---

## Tech Stack
- **Frontend:** EJS, CSS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT, Sessions
- **Version Control:** Git & GitHub

---

## Features (Implemented / In Progress)
- Listings creation and management
- Reviews system (add / delete / validate)
- Error handling and input validation

---

## Development Workflow
